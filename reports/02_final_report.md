### 3-2. 왜 첫날부터 터졌나 — 6개 요인 [추정, 첨부 관찰 결합]

1. **검증된 그릇 + 비어 있던 소재.** 상단 채널 바, '미식 | 날짜 | 댓글 9999' 가짜 게시글 헤더, 제목 고정, 1~2줄 자막, 가운데 이미지 박스로 된 **커뮤니티 글 캡처형 그릇**에, 체계적으로 다루는 채널이 없던 '프랜차이즈 식품 뒷얘기'를 담았습니다. 시청자 학습 비용이 0이었습니다.
2. **0.5초 이해.** 제목 = 썸네일 = 첫 프레임 = 고정 헤더입니다. 중간 유입자도 즉시 맥락을 파악합니다.
3. **익숙함 × 호기심 격차.** 전 국민이 아는 브랜드 + 몰랐던 사실. 첨부 집계로 전체의 34%가 '한국인/전국민/브랜드명'이 주어인 제목입니다.
4. **검증 가능한 결론 → 반응.** 좋아요율 최상위가 전부 '카피 제품 특정 가능'형입니다: 치즈스틱 1.85%, 맘스터치 1.82%, 청년다방 소스 1.65% (평균 0.93%) [첨부].
5. **물량.** 첫 3개월 45편. 영상마다 받는 초기 노출 테스트(복권)를 최대한 많이 샀고, 알고리즘이 시청자층을 빨리 학습했습니다.
6. **트렌드 순풍.** 두쫀쿠 열풍은 2025년 연말 본격화, 2026년 1월 정점이었습니다 [웹확인]. 1월 코호트의 두쫀쿠 6연작과 겹칩니다. 소재의 실재도 확인했습니다:
   - 최고 조회 영상의 코스트코 코리아 'Nusspo 두바이 초콜릿 크림 스프레드 1kg'은 **헤이즐넛·피스타치오 크림 반반, 카다이프 3%** 제품으로 실재합니다. 대본의 "크림을 분리해서 출시" 설명과 일치합니다 [웹확인].
   - 신선설농탕 '신선 왕만두'는 실재하고 "SNS에서 화제" 언급도 있으나, 정승제 발언과의 연결은 확인하지 못했습니다 [웹확인].

## 5. 제작 방식 역설계

> 레이아웃, 소스, 음성의 원관찰은 첨부 보고서(6편 프레임 분해, 자동자막 전사, 음성 피치 분석)에 근거합니다. 해석과 도구 추정은 통합본입니다.

### 5-1. 화면 템플릿 [첨부 관찰]

```
┌─────────────────────────────┐
│ » 맛있는 친구들 🍴            │ ← 연두색 헤더 바 (채널명 고정)
│ [味] 미식 | 날짜 | 댓글 9999   │ ← 커뮤니티 게시글 헤더 흉내
│ 한국 코스트코가 억울했던 이유   │ ← 제목 고정 (= 썸네일 = 헤더)
│ 최근 코스트코는                │ ← 나레이션 자막 1~2줄 (굵은 검정)
│ ┌───────────────────┐      │
│ │  이미지 / 짧은 클립  │      │ ← 중단 박스에만 이미지 (비율 통일 불필요)
│ └───────────────────┘      │
│        (흰 여백)              │ ← 하단 비움 (쇼츠 UI 겹침 회피)
└─────────────────────────────┘
0초 첫 프레임 = 검은 배경 대형 제목 카드 (썸네일 역할)
컷 전환 약 2~3초 / 35초에 이미지 12~15장 / 화려한 모션 없음, 저음량 BGM
```

**이 템플릿의 천재성은 '소스 비율 자유'입니다.** 가로, 세로, 정사각, 캡처를 아무거나 박스에 넣으면 됩니다. 수집 속도가 압도적으로 빨라지고, 이게 하루 1편을 가능하게 했습니다.

### 5-2. 대본 [첨부 전사 + 구조 해석]

**실제 대본 일부** ('한국 코스트코가 억울했던 이유', 34초):
> "한국 코스트코가 억울했던 이유. 최근 코스트코는 비싼 두바이를 저격한 두바이 스프레드를 출시했는데 … 유독 한국에선 '이거 그냥 초코맛 카다이프 아니야?'라며 반응이 안 좋았다고 함. 사실 이는 한국인들의 스프레드 먹는 방식이 잘못됐기 때문인데 … 비빔밥의 나라 한국인들은 '뭐야 크림이 두 개네, 그냥 비벼 버려야지'라며 두 개의 맛을 혼합해 버렸고…"

**고정 구조:** ①제목 그대로 읽기 → ②사건 → ③"사실은/하지만" 반전 → ④**가상 대사 재연**(시청자·기업의 속마음) → ⑤"현재는 ~라고 함" 근황.
**말투:** '~함/~음/~거/~래' 커뮤니티 요약체, 근거는 '~라고 함'. **분량:** 35초에 공백 제외 200~260자, 초당 6~7자 고속.

### 5-3. 음성 [첨부 측정 + 도구 추정]

- 4편의 기본주파수 중앙값이 177~186Hz로 **첫 영상부터 동일 화자**이고, 호흡 흔적 없이 음량이 균일합니다 [첨부].
- 판정: **한국어 TTS 또는 사람 녹음 1.15~1.3배속 + 노멀라이즈** (첨부·v1 공통). 도구 후보 [추정]: 클로바더빙, 타입캐스트, Vrew AI 목소리(한국어 음성 다수), CapCut TTS. 공개 정보로는 특정할 수 없습니다.

## 6. 수익 추정 (통합)

### 6-1. 쇼츠 수익 구조 [웹확인]

1. 국가별 쇼츠 피드 광고 수익에서 음악 라이선스 비용을 뺀 나머지가 크리에이터 풀이 됩니다.

3. **2025-03-31부터 공개 조회수는 재생·반복재생마다 카운트됩니다. 수익 기준은 engaged views입니다.** 이 채널은 전 기간이 변경 이후라, 공개 조회수 × RPM은 과대추정입니다. 첨부 보고서는 이 점을 반영하지 않았습니다.

| **백 카탈로그 수명**: 신작이 죽어도 하루 6만 회 | **업로드 체력 의존**: 쉬면 즉시 꺾임 (6월 휴방 → 회복 실패) |
| **정체성**: '한국 식품 소비문화' 세계관, 민족성 개그 | **근거 '~라고 함'**: 기업 의인화 과장 → 대응 리스크 |
| **매체력 검증**: MCN 광고 문의 유입 | **협찬 궁합 불량**: 돈이 되는 순간 채널 가치 하락 |

### 9-1. 결론

| 질문 | 답 |

| 기술적으로 완전 자동(주제 선정 → 업로드)이 가능한가? | **가능합니다.** 부품이 전부 존재합니다: LLM + 웹검색(리서치·대본), 일본어 TTS(타임스탬프 포함), 프로그래매틱 렌더링, YouTube Data/Analytics API |

**토픽 점수식 (초기값, 30편 이후 성과로 학습):**
`점수 = 0.25·브랜드 인지도 + 0.20·검증 가능성(실물 특정 가능) + 0.15·트렌드 속도 + 0.10·썰 밀도(반전) + 0.10·논쟁성 + 0.10·제휴 적합도 − 0.10·경쟁 포화 − 0.15·법적 위험 − 0.15·자기 중복(30일 내 동일 브랜드)`

**소재 우선순위 사다리 (권리 안전도 순):**
1. **자체 촬영** (실물, 뒷면 제조자 표시 클로즈업, 진열). 가장 안전하고 '양산형' 판정 방어력 최고
2. **공식 보도자료 이미지** (PR TIMES 등, 이용 조건 건별 확인)
3. **인용형 스크린샷** (공식 상품 페이지, 저작권법 32조 요건을 템플릿이 강제: 주종관계·명료구별·「出典: ○○公式サイト」 자동 표기)
4. 무료 상업용 스톡 (Pexels, Pixabay API 등)

2. **실물 증거:** 편당 최소 2컷 자체 촬영 (실물, 라벨 클로즈업). 슬라이드쇼가 아니라 취재물로 보이게.
3. **음성 정체성:** 범용 캐릭터 대신 본인 음성 클론 또는 고유 음성 + 고정 오프닝·엔딩 멘트.
4. **템플릿 변주:** 3계열(카드형 / 비교 분할형 / 랭킹형) × 시리즈 색. 같은 레이아웃 연속 금지.
5. **업로드 절제:** 하루 1~2편 상한 (일본 정지 사례의 공통점은 매일 대량 투고).
6. **출처 공개:** 설명란에 출처 URL 자동 기재 → 신뢰, 법적 방어, 교육적 가치를 동시에.

**タイトル: 日本人だけがクリスマスにケンタッキーを食べる理由**
> 日本人だけがクリスマスにケンタッキーを食べる理由。実はこれ、海外ではほぼ見られない日本だけの習慣らしい。きっかけは1970年代、とある外国人客の「日本じゃ七面鳥が手に入らないから、チキンで我慢するしかない」という一言。これを聞いた店長が「じゃあクリスマスはチキンでいいじゃん」とひらめき、1974年に『クリスマスにはケンタッキー』キャンペーンがスタート。これが大当たりして、今では予約しないと買えないレベルの国民行事に。ちなみにアメリカ人にこの話をすると「なんでKFC？」ってガチで驚かれるんだとか。あなたはクリスマス、チキン派？ケーキだけ派？

구조: ①제목 읽기 → ②「実は」 반전 → ③가상 대사 → ④전개 → ⑤현재 → ⑥여운 → **⑦편 가르기 질문**(대조 후 추가).

**PB 계열 템플릿 (빈칸은 팩트팩에서 채움):**
> 【商品名】、実は作ってるのは【メーカー】だったって知ってた？パッケージ裏の製造者欄を見ると…【根拠】。しかも中身は【NB商品】とほぼ同じ【比較ポイント】なのに、値段は【差額】も安いらしい。ネットでは「【反応(出典あり)】」との声も。あなたはPB派？本家派？
